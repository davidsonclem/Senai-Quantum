# Senai-Quantum

Repositório de exercícios e materiais de estudo em Computação Quântica da Pós-graduação Senai.

## 📚 Sobre

Este repositório contém exercícios, exemplos práticos e materiais de estudo sobre Computação Quântica, desenvolvidos durante o curso de Pós-graduação. O objetivo é consolidar o aprendizado através de exercícios teóricos e implementações práticas utilizando frameworks como Qiskit.

## 🗂️ Estrutura do Repositório

```
Senai-Quantum/
├── exercicios/
│   ├── 01-fundamentos/          # Conceitos básicos de computação quântica
│   ├── 02-portas-quanticas/     # Exercícios sobre portas quânticas
│   ├── 03-circuitos-quanticos/  # Construção e análise de circuitos
│   ├── 04-algoritmos/           # Algoritmos quânticos clássicos
│   └── 05-aplicacoes/           # Aplicações práticas
├── exemplos/
│   └── qiskit/                  # Exemplos de código usando Qiskit
└── recursos/                    # Materiais de apoio e referências
```

## 🚀 Como Começar

### Pré-requisitos

Para executar os exemplos práticos, você precisará de:

- Python 3.8 ou superior
- Qiskit (framework de computação quântica da IBM)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/davidsonclem/Senai-Quantum.git
cd Senai-Quantum

# Crie um ambiente virtual (recomendado)
python -m venv venv
source venv/bin/activate  # No Windows: venv\Scripts\activate

# Instale as dependências
pip install qiskit qiskit-aer matplotlib numpy
```

## 📖 Tópicos Abordados

### 1. Fundamentos
- Superposição quântica
- Emaranhamento quântico
- Notação de Dirac (bra-ket)
- Qubits e estados quânticos

### 2. Portas Quânticas
- Portas de Pauli (X, Y, Z)
- Porta Hadamard (H)
- Portas de fase (S, T)
- Porta CNOT e outras portas de múltiplos qubits

### 3. Circuitos Quânticos
- Construção de circuitos
- Medição de qubits
- Visualização de circuitos

### 4. Algoritmos Quânticos
- Algoritmo de Deutsch-Jozsa
- Algoritmo de Grover
- Transformada de Fourier Quântica (QFT)
- Algoritmo de Shor (conceitual)

### 5. Aplicações
- Criptografia quântica
- Simulação quântica
- Otimização quântica
