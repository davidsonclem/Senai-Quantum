Repositório acadêmico contendo implementações, experimentos e análises desenvolvidos durante a **Especialização em Computação Quântica** na Universidade SENAI CIMATEC.

---

## 📚 Sobre o Programa

Este repositório documenta a jornada de aprendizado em computação quântica, abrangendo desde os fundamentos matemáticos e físicos até a implementação prática de algoritmos quânticos. O conteúdo reflete o trabalho desenvolvido nas disciplinas do programa de especialização, com ênfase em simulações computacionais utilizando o framework Qiskit.

## 🗂️ Estrutura do Repositório

O repositório está organizado por módulos práticos, cada um contendo notebooks Jupyter, documentação técnica e resultados de experimentos:

```
├── pratico_01/
│   └── hands-on_01/           # Circuitos quânticos e visualização na Esfera de Bloch
├── pratico_02/                # [Em desenvolvimento]
└── ...
```

Cada diretório de hands-on contém:
- **Notebooks (.ipynb):** Implementações executáveis com análises passo a passo
- **README.md:** Documentação técnica detalhada, fundamentação teórica e resultados
- **Recursos adicionais:** Visualizações, diagramas de circuitos e dados de simulação

## 🎯 Áreas de Estudo

Os experimentos e implementações cobrem os seguintes tópicos fundamentais:

- **Mecânica Quântica para Computação:** Superposição, entrelaçamento, medição e colapso de estados
- **Portas Quânticas:** Operadores unitários de 1 e 2 qubits (Pauli, Hadamard, CNOT, Toffoli)
- **Circuitos Quânticos:** Construção, otimização e análise de circuitos compostos
- **Visualização de Estados:** Representação vetorial na Esfera de Bloch e análise de statevectors
- **Algoritmos Quânticos:** Implementação de algoritmos clássicos da computação quântica

## 🚀 Reproduzindo os Experimentos

Para executar localmente os notebooks deste repositório:

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/senai.git
cd senai

# Instale as dependências (recomendado: ambiente virtual)
pip install qiskit qiskit_aer matplotlib numpy jupyter

# Inicie o Jupyter Notebook
jupyter notebook
```

Alternativamente, todos os notebooks podem ser executados diretamente no **Google Colab** sem necessidade de instalação local.
