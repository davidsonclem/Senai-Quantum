### 💻 Opção 3: Clone Local
Clone o repositório e execute na sua máquina:

```bash
# Clone o repositório
git clone https://github.com/davidsonclem/senai-quantum.git

# Navegue até o notebook
cd senai-quantum/10_Correcao_e_Mitigacao_de_Erros_em_computacao_quantica/hands_on/01_02/notebook/

# Inicie o Jupyter
jupyter notebook HandsOn1_Codigo_de_Shor.ipynb
```

**Requisitos:**
```bash
pip install jupyter qiskit qiskit-aer numpy matplotlib
```
